# Falcon Arena 🦅⚡

**Live Interactive Trivia, Rebus Puzzles, Icebreakers, Squads, 4-Location Cup & Town Hall Lucky Draw for Falcon Corporation Limited**

Falcon Arena is an interactive team engagement platform purpose-built for **Falcon Corporation Limited** across its **4 operational locations**:
1. **Lekki Corporate HQ** (`Lekki HQ`)
2. **Ikorodu Gas Plant / LDC** (`Ikorodu LDC`)
3. **Port Harcourt (Rumuolumeni)** (`Port Harcourt`)
4. **Lekki Free Trade Zone** (`Lekki FTZ`)

---

## ✨ Key Features

1. **Speed Trivia, Visual Rebus Puzzles & Answer Streaks**:
   - Millisecond reaction scoring (up to 1,000 base points per round + streak bonuses up to +500 pts + **2x Double Energy** rounds).
   - Dedicated **Friday Rebus Puzzles** arena featuring visual wordplay boxes, positioning riddles, and emoji-word clues.
   - **"Team Talk" Huddle Timer**: Configurable countdown before answer buttons unlock so squads and office locations can confer.
2. **Majority Wins & Live Icebreaker Polls**:
   - **Majority Wins**: No textbook answer—everyone votes on a workplace dilemma or fun prompt, and staff whose vote matches the **Falcon Room Majority** win **+750 points**!
   - **Live Icebreaker Polls**: Everyone earns +300 participation points while the presenter stage reveals both company-wide percentages and how each of the 4 locations voted.
   - **Mobile "Personal Mode"**: Displays full question prompts, Rebus clues, and option labels directly on every employee's smartphone.
3. **Triple Leaderboard Architecture**:
   - **Falcon 4-Location Cup**: Live standings comparing **Lekki HQ**, **Ikorodu LDC**, **Port Harcourt**, and **Lekki Free Trade Zone** (toggleable between **Normalized Average Score per Staff** and **Total Points**).
   - **Falcon Squad Standings**: Cross-location teams (*Delta Flames*, *Pipeline Pioneers*, *City Gate Guardians*, *Jetty Blazers*, *Pressure Titans*, *Sky Falcons*).
   - **Individual Leaderboard** + **1-Click CSV Export** for HR / Corporate Communications.
4. **Town Hall Lucky Draw**:
   - Built-in animated slot-drum raffle to draw winners from all joined staff or filtered by a specific Falcon location, with "Exclude previous winners" protection.

## 🚀 Deploying to Vercel

1. Upload the files inside `github-upload-ready` to your GitHub repository (or run `deploy-to-vercel.bat`).
2. Import the repository at [vercel.com/new](https://vercel.com/new) and click **Deploy**.
